# Carisma House

صفحة هبوط عربية RTL لمتجر مستلزمات أناقة رجالية. تتضمن نافذة طلب أولية بقوائم ولاية/دائرة/بلدية مبنية على حزمة [`algeria-geo`](https://github.com/test-bit-sys/algeria-geo).

## التشغيل المحلي

يتطلب Node.js 20.19+ أو 22.12+ لتشغيل إصدار Vite المستخدم.

```bash
npm install
npm run dev
```

لبناء نسخة النشر والتحقق منها:

```bash
npm run build
npm run preview
```

يمكن نشر المشروع كـ Vite static site على Vercel باستخدام `npm run build` كمهمة البناء و`dist` كمجلد الإخراج.

## نافذة الطلب

- افتحها من أزرار طلب المنتجات أو «ابدأ طلبك».
- اختر الولاية؛ قائمة الدوائر اختيارية، والبلديات تُصفّى حسب الولاية أو الدائرة.
- يمكن البحث في حقول الدائرة والبلدية بالعربية أو الفرنسية من اقتراحات المتصفح.
- يتحقق النموذج من رقم هاتف محمول جزائري بصيغة محلية أو `+213` ومن توافق البلدية مع الولاية.
- حاليًا يعرض النموذج معاينة قابلة للنسخ فقط؛ **لا يرسل أو يخزن بيانات العملاء**. يلزم ربط Firebase أو نقطة استقبال طلبات قبل استخدامه لاستقبال طلبات حقيقية.

## بيانات المناطق والتراخيص

تأتي بيانات التقسيمات من حزمة `algeria-geo`. راجع [مستودعها](https://github.com/test-bit-sys/algeria-geo) وملف `NOTICE` الخاص بها لمعلومات الترخيص والمصادر والإسناد، خصوصًا عند توزيع بيانات الخرائط أو الإحداثيات.
